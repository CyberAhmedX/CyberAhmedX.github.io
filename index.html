CASE // NETSCAN-2026 LAB

Network Security Scanner with Firewall Rule Simulator

A real time network scanner and firewall simulator built with Flask and Nmap. Supports TCP SYN, UDP and service version scans with live WebSocket updates. With admin or root rights, deny rules run a real netsh or iptables command for that IP and port, dropping matching traffic at the OS level, and allow rules win over deny rules on both Linux and Windows. Later added a scan diff that flags newly opened ports, auto-expiring blocks with an audit log, subnet and port-range rules, and fixed a command injection found in self-review.
